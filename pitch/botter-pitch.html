BOTTER
05
Owl.
Orchestration Writeup Language
The language of FLOW.md.
English, with KEYWORDS.
STEP 1: GATHER ASK USER "What do you sell, and to which clients?" SAVE answer INTO VARIABLE `target` EXECUTE tool `scrape_leads` with payload { "query": `target` } SAVE result INTO VARIABLE `leads` IF `leads` IS EMPTY THEN RETURN "No leads found. Try another city." END IF
BOTTER
06
Compiled

It refuses to build
a broken flow.

FLOW.md:22: error: unknown keyword INVOCATE; did you mean INVOKE? FLOW.md:26: error: EXECUTE tool `send_mail`: no such tool FLOW.md:28: error: `pich` is used before it is set

Then your own LLM reviews the logic, before anything is built.

07
The .bot file

One file is
the whole agent.

botcoreRuntime: interpreter, HTTPS, sandbox
agent.md + FLOW.mdRead-only, as written
skills/Playbooks
tools/Programs
checksumTamper check

Static x86-64 Linux executable. No install, no runtime, no dependencies.

Nothing is generated. It runs exactly the files you wrote. Built in 2.7 ms.

Checksummed. A truncated or modified file refuses to start.

BOTTER
09
Bring your own key

Your model. Your key.
Entered once.

Gemini
OpenAI
OpenRouter
Groq
Ollama (local)
Any OpenAI-compatible URL

The key is cached in the kernel keyring, in RAM only, until the machine reboots. No re-entering it on every run: ideal for agents that live on a server.

BOTTER
10

Safe by default.
Private by design.

Sandboxed

Every tool and shell command runs under Landlock. The rest of your home directory is invisible.

Nothing phones home

No telemetry, no accounts, no update checks. One connection: the LLM provider you chose.

An offline switch

Set "internet": false and the kernel cuts the agent's tools off the network.
